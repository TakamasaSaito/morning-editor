# 004: 週次号はweb検索なし

日付: 2026-07-25
状態: 採用

## 決定

週次まとめ号(weekly.py)の生成ではweb検索ツールを使わず、直近7日分のbrief.jsonのみを入力とする。

## 理由

- 週次号の役割は「その週に届いた朝刊を振り返る編集長コラム」であり、新規情報収集は不要
- web検索を使うと週の出来事ではなく最新状況を反映した別の記事が生成されてしまう
- APIコスト削減(web検索ツール呼び出し分を省ける)
- タイムアウトリスクを下げられる(週次号はActionsのtimeout-minutes: 20と短め)

## 影響

- weekly.pyでは`tools`パラメータを渡さずClaudeを呼び出す
- brief.jsonが存在しない日付はスキップして週次号を生成する
