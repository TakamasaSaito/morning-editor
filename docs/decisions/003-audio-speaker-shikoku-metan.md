# 003: 音声話者は四国めたんノーマル・速度1.1

日付: 2026-07-25
状態: 採用

## 決定

VOICEVOX話者IDを 2(四国めたんノーマル)、速度スケールを 1.1 に固定する。

## 理由

- ずんだもん(ID:3)・ずんだもんあまあま(ID:1)・四国めたんノーマル(ID:2)の3話者で試聴比較
- 朝のニュース読み上げとして四国めたんノーマルが最も落ち着いた印象で聞きやすいと判断
- 速度1.0はやや間延びを感じるため1.1に微調整、1.2以上は聞き取りにくい

## 影響

- config.yaml の `audio.speaker_id: 2` / `speed_scale: 1.1` がデフォルト設定として定まる
- 他話者への切り替えはconfig.yamlを編集すれば即座に反映される(変更容易)
