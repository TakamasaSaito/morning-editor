OpenAI、未成年専用ChatGPTを世界展開

OpenAIは8月18日、13〜17歳向けの専用モード「ChatGPT for Teens」のグローバル展開を開始した。自己申告または年齢推定AIが17歳以下と判定したユーザーに自動適用され、自傷・ロマンティックな会話の遮断や保護者通知機能などが標準搭載される。

ChatGPTが9億人/週の利用者を持つ中、未成年への安全設計がようやく義務化された形であり、AI規制のグローバルな潮流を象徴する。訴訟リスクと8520億ドル規模のIPO準備を抱えるOpenAIにとって、子ども向け安全対策は経営上の最重要課題でもある。

背景

4年越しでようやく未成年ガード実装

2022年末のChatGPT登場以来、未成年向けの実効的なガードレールは存在しなかった。複数の自傷・自殺に関わる訴訟が提起され、米議会や規制当局の圧力が強まる中での対応となる。EUのAI透明化義務（8月2日施行）も追い風となり、モデルへの年齢推定機能の組み込みが加速した。

展望

他社・他国へ安全設計圧力が波及

展開は2週間以内に完了予定で、オーストラリアは9月8日予定と報じられている。他の生成AIサービス（Gemini、Claudeなど）にも同様の未成年モード整備圧力が高まる可能性がある。OpenAIのIPO（S-1提出が間近と報じられている）に向けて、安全性の「見える化」が投資家評価に影響するだろう。

影響

AI利用ポリシーに属性別設計の視点を

エンタープライズ用途への直接影響は限定的だが、従業員の子弟や教育機関との連携プロジェクトでAIガバナンスの問いが生じる可能性がある。企業内AIガバナンス策定において「年齢・対象者別のモデルスペック」という考え方が参照モデルになり得るだろう。生成AI活用ポリシーにユーザー属性別の制御設計を盛り込む動きが業界標準になる可能性がある。

  • 社内AI利用ポリシーにユーザー属性・用途別の制御要件を盛り込む検討を開始する
  • 教育機関や取引先との生成AI連携案件で、未成年ユーザーへの配慮事項を確認しておく

GitHub Copilot自動修正がSnowflake脆弱性を生成
セキュリティGitHub CopilotSnowflake
背景

AIパッチが公式OSSに脆弱性を注入

GitHub Copilot AutofixはPRやIssueに対し自動でセキュリティ修正パッチを提案する機能。今回は安全な入力パターンをGitHub Issueタイトルのraw文字列補間に置き換えるパッチを生成し、シェルインジェクションの穴を開けた。Snowflake自身のコネクタリポジトリへのマージが被害を拡大させた。

展望

AI自動修正の人間監査要件が標準化へ

GitHub・Snowflake両社の対応状況は報道時点では未確認。AI自動修正ツールのレビュー・承認プロセスに人間の監査ステップを設ける要件が、エンタープライズのDevSecOpsポリシーに盛り込まれる動きが加速するだろう。

影響

Snowflake環境とAutofixポリシーの即時点検を

Snowflakeを利用した社内データ基盤・分析環境では、snowflake-connector-netのバージョン確認とパッチ適用状況の点検が必要な可能性がある。GitHub Copilot Autofixを有効化したリポジトリ運用ポリシーの見直しも検討に値するだろう。

  • 社内Snowflake環境で使用するsnowflake-connector-netのバージョンを確認し、影響範囲を評価する
  • GitHub Copilot Autofixが有効なリポジトリの自動マージルールを見直し、セキュリティレビュー必須化を検討する
