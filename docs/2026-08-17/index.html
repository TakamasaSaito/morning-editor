DeepSeek V4 Pro正式公開・値上げ断行

中国AI企業DeepSeekは2026年8月13日、旗艦モデル『DeepSeek-V4-Pro』（バージョン0813）をアプリ・ウェブ・API全面でGA（正式版）リリースした。同日MIT License下でHugging Faceに重みを公開し、8月16日16:00 UTCよりピーク／オフピーク2段階の新料金体系が適用されている。

エージェント特化設計・100万トークンコンテキスト・OpenAI Responses API互換という三点が、既存エンタープライズ統合基盤への即時組み込みを可能にする。一方で出力トークン単価がピーク時に従来比約4.6倍へ跳ね上がっており、コスト前提の見直しなしに本番移行すると予算超過リスクが生じる。

背景

旗艦モデルGA・オープンウェイト公開

DeepSeekはV4-Pro-0813をGA扱いとし、MIT Licenseで重みを公開した。エージェント向けにOpenAI Responses API形式をネイティブサポートし、Codexとのワンクリック連携も実装。思考量をlow/high/maxの三段階で制御できる適応型推論が特徴で、開発者がAPIエンドポイント名を変えずに移行できる後方互換設計が採られている。

展望

オフピーク活用でコスト半減の余地

オフピーク料金はピーク比50%割引のため、バッチ処理やインデックス更新など非同期ワークロードをオフピーク帯（UTC 10:00〜01:00）に集約する運用最適化が現実解となる。今後の競合（OpenAI、Anthropic）の価格追随次第で、エンタープライズAI API市場全体の料金水準が変動する可能性がある。

影響

API予算の即時再試算が必要

エンタープライズ統合基盤でDeepSeek APIを採用・検討している場合、8月16日以降のコスト試算を即時再計算する必要があるだろう。OpenAI Responses API互換により既存エージェントフレームワークとの統合コストは低減される可能性がある一方、ピーク帯で稼働するリアルタイム推論は予算超過リスクを伴う可能性がある。

  • DeepSeek API利用中の本番ワークロードについて、8月16日以降の新料金でのコスト試算を再実施する
  • バッチ処理・非同期推論ジョブをUTC 10:00〜01:00のオフピーク帯にスケジューリングし直すことを検討する
  • 既存のOpenAI Responses API対応エージェント基盤へのV4-Pro組み込みPoC計画を立案する
用語解説
DeepSeek V4 Pro（GA） 中国AI企業DeepSeekの旗艦言語モデルの正式版。プレビューを経て2026年8月13日に全面公開され、エージェント処理に特化した設計と100万トークンコンテキストが特徴。

背景

CVE-2026-34263はSpring Securityの設定不備により、未認証のユーザーが悪意ある入力を注入しサーバーサイドのコードを実行できる欠陥である。SAPは5月と7月のパッチデーでいずれも修正を提供済みで、8月のSAP Security Patch Dayでも追加修正が行われている。

展望

BleepingComputerの報道によると、同脆弱性を含む複数のSAP CVEがCISAの『既知の悪用済み脆弱性』カタログに追加されてきた経緯があり、今後もランサムウェアを含む攻撃への転用が懸念される。

影響

自社またはクライアントのSAP Commerce Cloud環境について、5月・7月パッチの適用状況を即時確認する必要がある可能性がある。SAP BTPやS/4HANAを含む周辺製品にも8月パッチデーの別脆弱性が存在するため、パッチ管理台帳の全数確認が推奨されるだろう。

  • SAP Commerce Cloud・S/4HANA環境のパッチ適用状況（CVE-2026-34263・CVE-2026-34260）を確認し、未適用であれば緊急対応をベンダーと調整する
  • SAP BTPのApprouterを含む8月パッチデーの修正内容をsupport.sap.comで確認し、自社環境への影響範囲を評価する

背景

2026年6月17日署名のMOU（14項目）が定めた60日間の無償通航が8月中旬に期限を迎えた。南側（オマーン回廊）と北側（イラン指定航路）どちらが正当ルートかをめぐる争いも継続中で、機雷警戒・GPS障害・空船の偏在によって船腹配置は正常化していない。

展望

イランは通航料を制度化する意向を示しているが、米国・欧州・湾岸諸国は国際水路への課金に反対しており交渉の着地点は見えない。7月中旬以降LNG船の海峡通過は極めて限定的な状態にあり、カタール・UAEのLNG在庫が湾内に滞留しているとS&P Globalが報じている。

影響

エネルギーコストの変動はIT投資予算や顧客（エネルギー・製造業）のIT支出計画に影響を及ぼす可能性があるだろう。日本企業の製造・物流分野顧客向けシステム構築プロジェクトでは、エネルギー調達コスト前提の変化に伴う要件変更リスクを意識しておくべきかもしれない。

  • エネルギー・製造業顧客向けプロジェクトの前提コスト（物流・エネルギー）が変化していないか顧客に確認する
  • IT戦略資料のエネルギーコスト前提を8月中旬以降の情勢変化を織り込んで見直す
